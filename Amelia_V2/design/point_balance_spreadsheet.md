# The CK: Amelia V2 — Point Balance Spreadsheet

> Simulated playthroughs of 6 distinct player archetypes, tracking all stat accumulations chapter by chapter to verify ending reachability, identify dead ends, and validate the revised thresholds.

---

## METHODOLOGY

Each playstyle makes choices consistent with a personality. No player has perfect information — these simulations assume a player who *feels* like a particular archetype and naturally gravitates toward relevant options. Occasional suboptimal choices are included for realism.

**Key rules:**
- Each choice selects ONE option only
- Conditional scenes trigger only if requirements are met
- Karma Dice events use average rolls (no best/worst case)
- Negative point events apply when triggered
- The Sarah Score uses the exact formula: `({Sarah} × 3) + MH + SI + MC + ({Ella} × 0.5)`

## IDENTIFIED BALANCE ISSUES

### Issue 1: Scene 2.C Trigger Too Restrictive ⚠️
- **Problem:** Alchemist player can't trigger the tarot scene (needs SI≥3 or Liz≥1)
- **Impact:** Loses 1 OK point, making Alchemist ending borderline
- **Fix:** Add `OR OK ≥ 2` to trigger condition
- **Priority:** HIGH

### Issue 2: Healer's MC Is Tight
- **Problem:** A natural healer (MH-focused) ends with MC=15, one short of MC≥16 threshold
- **Impact:** The archetype's ending is technically missable with reasonable play
- **Assessment:** This is arguably *correct design* — the game says "caring about mental health isn't enough; you also need the courage to act." The near-miss creates a strong second-playthrough incentive.
- **Fix:** None needed. But consider adding one more MC opportunity in Ch9 (currently MC=0 in that chapter, which is unusual for a post-crisis chapter where moral courage should matter).
- **Priority:** LOW — monitor during playtesting

### Issue 3: The Whole Ending Is Very Hard
- **Problem:** The balanced player only reaches Bittersweet. The Whole (all≥12, none<8) requires *intentional* broad investment.
- **Assessment:** Correct by design. The Whole ending is the "postgame" reward for a player who understands the system from a previous playthrough. It should not be achievable on a first blind run.
- **Fix:** None needed.
- **Priority:** NONE

### Issue 4: Stat Floor at Zero
- **Problem:** Neglector playthrough shows negative stats (MH=-6)
- **Impact:** Purely technical — the Sarah Score formula can handle negatives, but display might look odd
- **Fix:** Floor all stats at 0 in code. Negative point events reduce toward 0 but never below.
- **Priority:** MEDIUM (implementation detail)

### Issue 5: MC Distribution Is Lumpy
- **Problem:** MC=0 available in Ch9 and Ch12. Most MC is in Ch3, 6, and 8 (moral confrontation chapters).
- **Assessment:** Thematically correct (moral courage is about confrontation), but means MC-focused players have "dead" chapters.
- **Fix:** Add one MC opportunity in Ch9 — perhaps a choice about whether to speak publicly about the Sarah crisis to help others. Fits the post-crisis narrative.
- **Priority:** LOW

### Issue 6: OK Path Social Cost
- **Problem:** The alchemist player naturally neglects social stats, leading to Sarah's death. With Elena bonus, partial save. Without, tragic.
- **Assessment:** This is **intentional design**. The game asks: what is knowledge worth if you don't use it to care for others? Elena's bonus represents the answer the tradition itself gives — true occult knowledge includes compassion. A player who pursues OK without Elena's social teaching still loses Sarah.
- **Fix:** None needed. This is the game's thesis.
- **Priority:** NONE (philosophical feature, not bug)

## CODE IMPLEMENTATION NOTES

### Stat Clamping
```python
init python:
    def clamp_stat(value):
        return max(0, value)
    
    def update_stat(stat_name, delta):
        current = getattr(store, stat_name)
        setattr(store, stat_name, clamp_stat(current + delta))
```

### Sarah Score Calculation
```python
label calculate_sarah_score:
    $ sarah_score = (sarah_relationship * 3) + stat_mh + stat_si + stat_mc + int(ella_relationship * 0.5)
    
    if mentor == "elena" and stat_ok >= 18:
        $ sarah_score += 10
    
    if sarah_score >= 45:
        $ sarah_outcome = "full_save"
    elif sarah_score >= 30:
        $ sarah_outcome = "late_save"
    elif sarah_score >= 15:
        $ sarah_outcome = "partial_save"
    else:
        $ sarah_outcome = "tragic"
        $ sarah_alive = False
    
    return
```

### Ending Determination

label determine_ending:
