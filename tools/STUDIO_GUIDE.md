# Amelia Studio — Enhanced Guide

Complete creative tools for generating voice and art assets for The CK visual novel.

## Features

### Voice Generation
- **Kokoro TTS** (local via Docker): Original voice generation system
- **Qwen3-TTS** (local API): Character-based voice synthesis with mood/emotion control
  - 17 predefined characters with authentic voices
  - Context-aware mood selection per character
  - Single generation mode with dropdowns
  - Batch CSV import for bulk generation

### Image Generation
- **fal.ai** (online API): External cloud-based generation (FLUX models)
- **Local SDXL** (img2img): Character sprite generation with anchor images
  - Anchor image selection with preview
  - Expression and outfit variations
  - Single generation mode
  - Batch CSV import for multiple variations

## Setup

### Prerequisites
- **Docker** and **docker-compose**
- **Python 3.9+** (for local SDXL server)
- **Qwen3-TTS** running locally (default: `http://127.0.0.1:42003`)
- **fal.ai API key** (optional, for online models)

### Installation

1. **Configure environment:**
   ```bash
   cd tools/studio
   cp .env.example .env
   # Edit .env to add your FAL_KEY (optional)
   ```

2. **Start the Studio:**
   ```bash
   cd tools
   ./start_studio.sh
   ```
   The UI will be available at http://localhost:8000

3. **Start Local SDXL Server (Optional):**
   ```bash
   cd tools
   ./start_sdxl_server.sh
   ```
   Leave this terminal open. First run downloads ~7GB of models.

## Hardware Detection & Info Display

- **Automatic Hardware Detection:** On every Studio launch, your system's hardware (CPU, RAM, GPU tier, CUDA/MPS support) is detected and written to `/output/hardware.json`.
- **Always Available in UI:** The Studio UI reads hardware info directly from this file, so hardware details are always visible—even if the SDXL server or backend services are down.
- **No Dependency on SDXL:** Hardware info is decoupled from SDXL/image generation. It is available as soon as the Studio starts.

## Voice Generation Guide

### Using Qwen3-TTS with Character Voices

#### Single Generation Mode

1. Navigate to the **Voice** tab
2. Select **Qwen3-TTS** mode
3. Choose:
   - **Character**: Amelia, Ella, Lucas, Prof. Hawthorne, etc.
   - **Mood**: Depends on character (e.g., Amelia: anxious, happy, determined)
   - **Speed**: 0.5 to 2.0 (default: 1.0)
4. Enter dialogue text
5. Optional: Specify output path (relative to `Amelia_V2/game/audio/narrator/`)
6. Click **Generate**

**Example:**
- Character: **Amelia**
- Mood: **anxious**
- Text: `"I keep reading about individuation but I can't even individuate myself from my mum's cooking."`
- Output: `Amelia_V2/game/audio/narrator/amelia_anxious_abc123.wav`

#### Batch CSV Mode

Create a CSV file with this format:

```csv
text,character,mood,speed,output_path
"Hello, welcome!",Amelia,happy,1.0,amelia_greeting.wav
"I understand.",Lucas,normal,0.9,lucas_response.wav
"You know what I think?",Lucas,vulnerable,1.0,lucas_vulnerable.wav
"Sorry — what were you saying?",Amelia,anxious,1.1,amelia_anxious_1.wav
```

1. Go to **Voice** tab → **Batch Mode**
2. Click **Upload CSV**
3. Select your CSV file
4. Review results (success/failed count)

All files save to `Amelia_V2/game/audio/narrator/`

## Image Generation Guide

### Using Local SDXL with Anchor Images

Every character has an **anchor image** — a master reference that defines their appearance. New images are generated by modifying this anchor with prompts.

#### Single Generation Mode

1. Navigate to **Images** tab → **Local SDXL**
2. Select:
   - **Character**: Amelia, Ella, Lucas, etc. (shows preview of anchor)
   - **Expression**: neutral, happy, sad, angry, thinking, etc.
   - **Outfit**: casual_a, academic, summer, etc.
3. Enter **prompt** describing the modification:
   - "Painterly illustration, Amelia looking thoughtful in autumn light"
   - "Ella smiling warmly, soft lighting"
4. Adjust:
   - **Strength**: 0.0 (no change) to 1.0 (complete transformation)  
     Recommended: 0.5-0.7 for expression changes
   - **Steps**: More steps = higher quality (default: 30)
5. Optional: Specify output path
6. Click **Generate**

Output saves to `Amelia_V2/game/images/characters/{character}/`

#### Batch CSV Mode

Create a CSV file:

```csv
prompt,character,expression,outfit,strength,output_path
"Amelia looking thoughtful in library",Amelia,thinking,casual_a,0.6,amelia_thinking_library.png
"Amelia smiling gently at sunset",Amelia,happy,casual_a,0.6,amelia_happy_sunset.png
"Lucas with headphones, focused",Lucas,neutral,casual,0.5,lucas_neutral_focused.png
"Ella laughing warmly",Ella,chatty,casual,0.6,ella_laughing.png
```

1. Go to **Images** → **Local SDXL** → **Batch Mode**
2. Upload CSV
3. Wait for batch processing (shows progress)

#### Anchor Image Management

**View all anchors:**
```
GET /api/images/anchors
```

**Preview an anchor:**
```
GET /api/images/anchors/Amelia/preview
```

**Check if SDXL server is running:**
```
GET /api/images/local/status
```

## API Reference

### Voice Endpoints

#### List Characters
```http
GET /api/voice/qwen/characters
```

Response:
```json
{
  "characters": [
    {
      "name": "Amelia",
      "description": "Warm, professional female voice with British accent",
      "moods": ["neutral", "anxious", "vulnerable", "passionate", ...]
    },
    ...
  ]
}
```

#### Get Character Moods
```http
GET /api/voice/qwen/characters/{character}/moods
```

#### Generate Single Voice
```http
POST /api/voice/qwen/generate
Content-Type: application/json

{
  "text": "Hello, welcome!",
  "character": "Amelia",
  "mood": "happy",
  "speed": 1.0,
  "output_path": "amelia_greeting.wav"
}
```

#### Batch Generate
```http
POST /api/voice/qwen/batch
Content-Type: multipart/form-data

file: voices.csv
```

### Image Endpoints

#### List Anchors
```http
GET /api/images/anchors
```

#### Get Anchor Details
```http
GET /api/images/anchors/{character}
```

#### Preview Anchor
```http
GET /api/images/anchors/{character}/preview
```

#### Check SDXL Status
```http
GET /api/images/local/status
```


## Troubleshooting

### Qwen3-TTS Not Responding
- Ensure Qwen3-TTS is running on `http://127.0.0.1:42003`
- Check API key is set to `your-api-key-1` (default)
- Test with: `curl http://127.0.0.1:42003/health`

### Local SDXL Not Working
- Start the server: `./start_sdxl_server.sh`
- First run downloads ~7GB (be patient)
- On Mac, it runs on CPU (slower but stable)
- Check status: `curl http://127.0.0.1:7861/health`

### Black Images from SDXL
- This was an issue with MPS on Mac — fixed by using CPU mode
- Ensure you're using the latest `sdxl_img2img_server.py`

### Docker Issues
- Make sure Docker Desktop is running
- Check logs: `cd tools/studio && docker-compose logs`
- Rebuild: `docker-compose down && docker-compose up --build`

## Example Workflows

### Workflow 1: Generate Dialogue for a Scene

You have script lines for Amelia and Lucas from Chapter 3.

1. Create `chapter3_dialogue.csv`:
   ```csv
   text,character,mood,speed,output_path
   "I keep thinking about what Maya said.",Amelia,thinking,1.0,ch3_amelia_1.wav
   "About the Tower card?",Lucas,normal,0.9,ch3_lucas_1.wav
   "Yeah. The destruction is the beginning.",Amelia,vulnerable,1.0,ch3_amelia_2.wav
   "That's one way to look at it.",Lucas,deadpan,0.9,ch3_lucas_2.wav
   ```

2. Go to **Voice** → **Batch Mode**
3. Upload `chapter3_dialogue.csv`
4. Files save to `Amelia_V2/game/audio/narrator/`
5. Convert to OGG: Use audio conversion tool

### Workflow 2: Generate Character Sprite Variations

You need Amelia in 3 moods for Chapter 1.

1. Create `amelia_ch1_sprites.csv`:
   ```csv
   prompt,character,expression,outfit,strength,output_path
   "Painterly illustration, anxious expression",Amelia,anxious,casual_a,0.6,amelia_anxious_ch1.png
   "Painterly illustration, neutral calm",Amelia,neutral,casual_a,0.6,amelia_neutral_ch1.png
   "Painterly illustration, gentle smile",Amelia,happy,casual_a,0.6,amelia_happy_ch1.png
   ```

2. Start SDXL server if not running
3. Go to **Images** → **Local SDXL** → **Batch Mode**
4. Upload `amelia_ch1_sprites.csv`
5. Images save to `Amelia_V2/game/images/characters/amelia/`
